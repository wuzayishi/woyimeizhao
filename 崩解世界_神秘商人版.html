玩家与怪物共用同一套锚点与强度分档；所有状态特效按精灵真实宽高等比定位，Boss 与小怪都不会出现特效飘到体外。连击数字与提示仍固定在右上角，不占战斗区域。

连 击 规 则

连续命中 3 次启动连击，之后在衔接窗口内再次命中即 +1；连击越高，伤害 / 攻速 / 暴击 / 移速 / 吸血 / 充能 / 击退加成越高（20 连击封顶）。
断连时进入一次「补救窗口」，迅速补上一次伤害即可维持；补救后若停手过久、或没能再次衔接，连击立即失效，且本次连击链不再给第二次补救机会。
连击数字、加成与全部状态提示统一固定在屏幕右上角的小徽标内，不遮挡战斗区域。

关 卡 非 重 复 性

全部 19 张地图各自使用唯一地面纹理、中心纹章、结构布局、宽高比、出生点、障碍组合、刷怪阵型与色调偏移；同一关内也不复用纹理与纹章基底。调试页可查看实时校验结果。

装 备 系 统

大厅里点击自己脚下的小球唤出本体栏，内含武器槽、护甲槽、饰品槽；走近双击神秘的商人打开货架。购买用金币，更高级的道具用宝石兑换。
关卡中击败小怪必定掉落金币，怪物等级越高掉得越多；等级 ≥5 的怪物有概率掉宝石，Boss 必掉。换图与关卡结算时，场上未拾取的货币会自动入账。
疾风拳套（测试装备）：攻速不再受武器频率限制，轻点即出招、长按自动连发；但两次攻击间隔越短，单次伤害越低（间隔 ≥0.30s 满伤，瞬连最低 18%）。放慢点击节奏即可回到满伤。

神 秘 商 人 · 限 量 货 架

每轮货架只上有限种类商品；大部分道具本轮限购，少数标「∞ 无限供应」。买完最后一次会提示售罄，按钮置灰；定时补货会重置库存并轮换货品，也可花宝石立即刷新，刷新时商人会播放补货动画。已拥有装备、已记录卷轴、已习得技能不再上架。

消 耗 品 · 药 水 与 卷 轴

神秘商人新增消耗品货架，用金币 / 宝石可重复购买，进战斗后按 B（或点按键区左上「背包」）打开局内背包使用。
药水：回血、机动、输出、防御、清弹幕解围、高风险爆发共 6 种；立即生效或持续计时，同类刷新不叠加，最多同时 4 种增益，且伤害 / 移速 / 承伤 / 攻速都有硬上限。
卷轴：使用后记录招式并自动销毁，招式永久保留；之后每次普攻从已记录招式中随机放出一个（扇形斩 / 环身斩 / 连锁雷 / 碎冰 / 汲血 / 延时爆核），最短间隔 0.22 秒。招式伤害是普攻的 30%~52%，不吃连击倍率与暴击，疾风拳套连发时同样按点击间隔衰减，防止靠无上限攻速刷招式。
已记录的卷轴不会再出现在购买列表；药水与卷轴的库存、招式记录都会写进存档。

技 能 卷 轴 · 格 挡 与 追 击

技能卷轴在神秘商人处购买，使用后习得并自动销毁，永久生效并写进存档；它们不进入普攻随机招式池，而是各自绑定独立的触发条件。
格挡：新增独立按键 F／按键区左上圆钮，以及左下角独立的格挡条。每次格挡消耗 25 点（满 100，可连按 4 次），姿态持续 0.45 秒；姿态内被命中即格挡成功：完全免伤，攻击者僵持 0.9 秒（不移动、不攻击、不接触伤害）。格挡条清空后进入 2.2 秒力竭，期间无法格挡，之后逐渐回复。
弹反：前置技能为格挡，未习得格挡时无法购买或使用；习得后每次格挡成功立即追加一次金色斩击，造成 55% 普攻伤害并强力击退。
冲刺斩击：冲刺结束瞬间自动接一次宽扇形横扫；突刺：同样在冲刺结束触发，但是沿冲刺方向的窄长直刺，击退更远。两者可同时生效，但都不吃连击倍率、暴击与吸血，且共用冲刺 CD，避免靠位移刷伤害。
调试页可一键习得全部技能与校验格挡条边界。

刀 光 与 刀 本 体 同 步

所有刀光都按武器本体绘制，不再出现「刀已经挥走、刀光留在原地」的脱节感。
角色每帧把真实锚点（含后坐、跳步、受击抖动）缓存下来，武器精灵、刀身拖尾、刀光与刀尖火花读同一个点；刀光角度与半径全部取自刀身几何（r0~r1、角偏移），挥砍时钟与武器同为 0.25s 衰减律。
刀光不再是向外扩散的静态弧，而是刀尖扫过的扇形拖尾：亮边永远压在刀身当前位置，尾部逐渐淡出；卷轴斩、二技能衔接普攻的特效起点也改从刀身可达位置发出，特效与命中判定同一个点。
其余环身冲击、弹幕、星芒改为「外柔光＋主色＋白芯＋弧上像素火花」分层绘制，全环保留扩散、定向弧只轻微外推。调试页可一键校验同步状态并连续挥砍观察。

护 甲 平 衡

8 件护甲以有效生命 EHP 为统一标尺（把生命上限、百分比减伤、固定格挡换算成「能扛多少点标准伤害」），面板里每件都标了「小伤 / Boss 重击」两个数值。
金币 4 件 EHP 约 130~144，靠机制区分：纯血 / 减伤 / 脱战回盾 / 近身反伤；宝石 4 件 EHP 约 160~229，对应减伤 / 血牛 / 格挡 / 顶配，价格 2~5 ◆ 随强度递增。
硬护栏：护甲槽唯一不可叠穿；塔罗与护甲减伤合并后最多 45%；移动速度最低 ×0.82；固定格挡每次至少仍受 1 点伤害，无法免疫；回盾需脱战 2.5 秒，挨打即中断；反伤为 tick 伤害，不刷连击 / 暴击 / 吸血。
因此没有「一件完爆全部」的护甲：重甲怕弹幕走位、格挡甲怕 Boss 重击、反伤甲怕远程、续航甲怕持续贴脸。换装按当前血量百分比换算，不会被白扣血。

开 发 者 模 式

输入密钥后开启开发者模式。开启瞬间默认解锁全部内容：所有卷轴技能（格挡 / 弹反 / 冲刺斩击 / 突刺）、普攻招式卷轴、全部装备与武器、护甲、饰品，以及全部药水道具，并补足金币与宝石。
密钥已改为纯小写拼音全拼（六个汉字的拼音连写：全小写、无空格、无声调、无大写），输入时只需英文键盘，不会调用中文输入法或安全键盘；设备自动首字母大写也能通过。旧的中文密钥已停用。
开启状态会持久化保存，之后每次启动都会自动补齐解锁；关闭模式不会回收已解锁的内容。已解锁内容写进存档，重置存档后只要模式仍开启，启动时也会重新补齐。
当前：关闭 · 需要密钥开启
